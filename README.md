# My Calculator

A small calculator website built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser, or run this command from the project folder:

```powershell
start .\index.html
```

## Push to GitHub

After creating an empty GitHub repository named `my-calculator`, run:

```powershell
git remote add origin https://github.com/YOUR-USERNAME/my-calculator.git
git branch -M main
git push -u origin main
```
